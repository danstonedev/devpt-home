# Local review materials

The accepted frontend now lives in the actual DevPT root: `index.html`, `teaching-library.js` and `teaching-library.css`. This folder retains source captures and historical review images only. Old standalone HTML/ZIP previews are superseded.

Use `npm run build:local` and `npm run preview:local` from devpt-home. Export the whole actual site with `npm run package:local -- <new-output-folder>`. The three scripts here are compatibility aliases to those commands.

See `../docs/local-site-preview.md` for the full local launcher and source ownership contract. No lesson builder is included in this pass.
