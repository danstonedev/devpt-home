# Gait lab: student and faculty critique

Local review, 20 October 2026. This evaluates the working native build; it does not assign clinical acceptance.

The current lab is an interactive motion explorer with formative knowledge practice. It does not yet demonstrate a student's ability to assess gait. Its strongest foundation is the real CC source motion, original teaching mannequin, selectable characters, reliable playback and measured comparisons. The next investment should improve the learning task rather than add more controls or characters.

## Three prepared tasks

**Find a stride · 3 minutes.** Start with the blank mannequin and one native CC take. Guide the learner through first same-foot contact, next same-foot contact and loop. Reveal one prompt at a time. A learner-selected interval remains their observation; it is not automatically a correct stride.

**Read the walk · 5 minutes.** Ask the learner to record limb, time and visible movement. Move from stance/swing to specific events after source annotations are reviewed. Let them compare side and front views at the same time. Separate what is visible from a possible explanation; an animation does not establish a diagnosis, pain, muscle force or ground-reaction force.

**Explore a restriction · 5 minutes.** Change one joint at a time. Ask for a prediction, apply the edit, jump to its greatest measured effect and compare original/edited at the same time. Then ask what actually changed. Keep a compact fixed-root/no-compensation indicator visible. A limited source rotation is not evidence that a real person will adopt that gait strategy.

Each task should open the model immediately, with a small progress indicator and one active instruction. Use optional drawers for graphs, the rubric and source details. Do not place this entire explanation on the student screen.

## What faculty need to assign it

Each prepared task needs one observable objective, approximate duration, exact starting setup, expected evidence and a small rubric. For example: **correct limb → relevant time/event → accurate observation → supported explanation**. Offer a reusable task link, student preview, reset and an optional response export. Keep discussion use available without accounts.

Basic exploration, prepared studies and link sharing can stay account-free. Cross-device lesson ownership can use an optional faculty account. Rosters, grades and secure assessment need a separate identity/persistence design; a public client-side quiz should not imply that infrastructure exists.

Keep three forms of evidence separate: knowledge-question responses, source-specific observations, and clinical competency. Do not roll them into a single mastery score. Exact model angle readings also need reproducible calibration and declared measurement scope before they become grading keys.

## Content that cannot be invented

The current enrolled CC selection has no reviewed contact-event annotations or packaged pathological gait clips. A short, reviewed annotation set is more valuable than many unannotated walks. Add contact/toe-off events and declared feedback tolerances at the source, with source hashes and review ownership. Keep learner marks separate from that reference.

For impairment recognition, acquire and review actual native CC source clips. Do not relabel procedural patterns, ROM-clipped motion, or character appearance as a native impairment demonstration. Functional limits and compensatory gait require their own supported implementation and validation.

## Immediate local corrections

The current iteration corrects the proportional phase display, labels phase timing as reference guidance, calls the quiz **Practice**, and adds navigation to the largest measured ROM change with explicit unchanged/refused states. The catalog title is **Gait lab**. Review also exposed an asynchronous calibration issue: idle animation could influence the first angle reference before a clip arrived. The local player now captures its own unchanged anatomical reference and placement before that delay; regression checks compare immediate and delayed loads.

These improve the existing explorer; guided tasks, source-event annotations, full study-state sharing and observation rubrics remain the next teaching milestones. Reproducible model readings are still distinct from validated clinical measurements.
